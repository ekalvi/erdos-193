What the coordinates mean

The planar coordinates encode the Gaussian direction in their low bits. The height uses the same exponent modulo four. Every exact step satisfies |dx|, |dy| ≤ 2 and 1 ≤ dz ≤ 7.

The height control changes only the on-screen aspect ratio. It never changes the stored integer coordinates or the proof artifact.
