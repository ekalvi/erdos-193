Scale and height

The complete order-12 Hilbert grid is 4,096 lattice units across. The 16 possible moves have lengths from 4.47 to 28.07 lattice units.

The height control changes only the on-screen aspect ratio. It reports exactly how much the stored height is compressed or stretched; the integer coordinates and proof artifact never change.
