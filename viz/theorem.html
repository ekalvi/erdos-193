Unconditional AI-assisted proof

What Lean checked

The repository contains a complete affirmative proof of Erdős Problem 193. Lean checked the infinite construction—not only the 500,000-step example. External mathematical review is still pending.

Why this matters

Ordinary testing can only check a finite number of robot steps. Lean checks the general argument for every future step and every possible group of three footprints. Its small trusted core rejects a proof if even one required logical step is missing.

Exact theorem shape

∃ (S : Set Point3) (P : ℕ → Point3),
  S.Finite ∧
  (∀ n, displacement (P n) (P (n+1)) ∈ S) ∧
  (∀ i<j<k, ¬ OrderedCollinear (P i) (P j) (P k))

Point3 has three integer coordinates. Because the third coordinate of P is strictly increasing, the ordered formulation covers every triple of distinct vertices after sorting by index.

The fixed step set

The theorem uses the explicit finite superset

S = { (dx,dy,dz) ∈ ℤ³ : −28≤dx,dy≤28 and 4≤dz≤28 }.

The proof does not assume that this is the smallest menu. It is a simple finite box containing every consecutive displacement. The generated 500,000-step prefix realizes exactly 16 distinct vectors.

Review boundary

A machine-checked proof can still formalize the wrong statement. The remaining human review questions are therefore concrete:

  1. Does OrderedCollinear, together with strictly increasing height, match ordinary collinearity for every triple of distinct vertices?
  2. Does the nested-even transducer equal the intended standard discrete Hilbert indexing?
  3. Does the finite-menu theorem exactly match the fixed-finite-step requirement in the Gerver–Ramsey problem?
  4. Are the source definitions free of an accidental narrowed domain?

The current answer inside the repository is yes, supported by the formal bridge lemmas and independent replay. External mathematical review is still pending.
