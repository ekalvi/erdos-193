Standalone handwritten demonstration

Construct the walk, then check a finite prefix yourself.

This deliberately direct Python program follows the proof skeleton: decode the discrete Hilbert path, steer every selected index to terminal state I, lift index into height, check the pair fingerprint, and search the chosen finite prefix for collinear triples.

Learning artifact, not the proof

A successful run checks only the finite prefix requested below. The manuscript and Lean development establish the unconditional infinite theorem.

Run in your browser

Choose a small prefix.

Pair checking is quadratic and triple checking is cubic, so the browser runner is intentionally capped at 150 points.

What the program exposes

The executable spine of the proof.

decode and H

Read even-padded base-4 digits, emit coordinate bits, and retain the terminal decoder state.

n_a

Use the four-state suffix lookup to choose one terminal-state-I index from each block of sixteen.

verify_pair_law

Check the two-adic vector fingerprint for every pair in the finite prefix.

verify_walk

Use exact integer arithmetic to reject every collinear triple in the finite prefix.
