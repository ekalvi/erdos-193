The architecture

1Trace the Hilbert path and encode its final state

The discrete Hilbert decoder maps each index \(n\) to a lattice point \(H(n)\in\mathbb N^2\). Consecutive indices are planar lattice neighbors. The decoder also ends in one of four orientation states \(I,S,C,T\).

Give those states cyclic labels and matching Gray-code corners:

\[ \begin{array}{c|cccc} g&I&S&C&T\\ \hline \lambda(g)&0&1&2&3\\ u_g&(0,0)&(0,1)&(1,1)&(1,0). \end{array} \]

Use every index and place its state code in the planar and height coordinates:

\[ G(n)=2H(n)+u_{\sigma(n)},\qquad z(n)=4n+\lambda(\sigma(n)),\qquad P_n=(G(n),z(n)). \]
One state, two matching encodings

The Gray-code corner and height residue carry the same cyclic label, synchronizing the parity calculation for every pair.

The binary fingerprint

2Equal terminal states expose the first mismatch

For a nonzero planar vector \(u=(u_x,u_y)\), let

\[ p(u)=\min\{\nu_2(u_x),\nu_2(u_y)\},\qquad V(u)=2p(u)+\mathbf 1_{\nu_2(u_x)=\nu_2(u_y)}. \]

If two Hilbert indices finish in the same state, their first differing base-4 digit from the low end controls both their index gap and the first nonzero binary scale of their planar chord:

\[ \sigma(m)=\sigma(n),\ m\ne n \quad\Longrightarrow\quad V(H(n)-H(m))=\nu_2(|n-m|). \]

A scalar contributes twice to the planar fingerprint because it shifts both coordinate streams:

\[V(ku)=V(u)+2\nu_2(k).\]
Complete the parity cases

3One identity holds for every pair

For \(d=n-m\), \(i=\lambda(\sigma(m))\), \(j=\lambda(\sigma(n))\), and \(X=H(n)-H(m)\),

\[ G(n)-G(m)=2X+c_j-c_i,\qquad z(n)-z(m)=4d+j-i. \]
  • If \(i=j\), the corner codes cancel and the same-state law shifts by two.
  • If \(j-i\) is odd, adjacent Gray-code corners change one planar parity bit; both sides have valuation \(0\).
  • If \(j-i=\pm2\), opposite corners change both planar parity bits; both sides have valuation \(1\).
All-pairs law

For every \(m\ne n\), \(V(G(n)-G(m))=\nu_2(|z(n)-z(m)|)\).

Assume a line

4Three pair laws demand an impossible parity

Suppose \(P_a,P_b,P_c\) are collinear for \(a<b<c\). Let their adjacent positive height gaps be \(A,B\) and planar chords be \(X,Y\). Collinearity gives \(BX=AY\).

Write \(A=gr\), \(B=gs\) with \(\gcd(r,s)=1\). Then an integer vector \(W\ne0\) satisfies \(X=rW\), \(Y=sW\). Applying the all-pairs law to the adjacent pairs forces \(r\) and \(s\) to be odd. Applying it to the endpoint chord \((r+s)W\) forces \(r+s\) to be odd.

Contradiction

Odd plus odd cannot be odd.

No three lifted points are collinear.

Finish the walk

5Every successive displacement comes from one finite box

The planar displacement is twice one Hilbert unit step plus a corner-code difference. Each planar coordinate therefore has absolute value at most \(3\). The height increment is \(4\) plus a label difference, hence lies between \(1\) and \(7\).

\[ S=\{(d_x,d_y,d_z)\in\mathbb Z^3: |d_x|,|d_y|\le3,\ 1\le d_z\le7\}. \]

The height is strictly increasing, so the sequence is infinite and has no repeated vertices. The previous section excludes every collinear triple.
