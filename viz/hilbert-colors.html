The selector made visible

Four states, sixteen suffixes, one chosen index per block

A Hilbert route is made from smaller copies of itself, each turned or reflected. The four colors visualize the route’s four possible terminal orientation states: right, up, down, and left. The proof may target any one state; the formal construction chooses identity state I, shown in blue.

The distinction that mattered for me

The 16 cells in a 4×4 block are not 16 states, and every blue cell is not selected. A fixed state-to-offset lookup chooses one representative from each block. White rings show those representatives.

Every cell has a base-4 address

Imagine zooming into the large square repeatedly. At each scale, one of four address digits chooses the next quarter. The address strip in the inspector records those nested choices. If that notation is unfamiliar, the guided pair-law lesson introduces it before using it.

How an address produces a terminal state

Start with the whole Hilbert square facing right. Read a cell’s base-4 address from left to right. Each digit chooses one quarter and updates the orientation carried into the next scale. After the final digit, the leftover orientation is the terminal state. The color is only this page’s label for that state; there is no score or search.

Where the arrows come from. The basic U enters at (0,0) and exits at (1,0), so it points left → right. Apply each state transformation to both endpoints: I: (0,0)→(1,0), S: (0,0)→(0,1), T: (1,1)→(1,0), and C: (1,1)→(0,1). Those transformed entry-to-exit pairs give the four displayed directions.
How a white ring is chosen. The selector does not search for the first blue cell. For each 16-index block, it computes the prefix state and uses the fixed lookup I→5, S→1, T→13, C→3. The chosen two-digit suffix has the same state contribution as the prefix; because each state is self-inverse, the two cancel and the completed index ends in state I. Other blue cells in the block are valid but unused.

Point inspector

Hover a cell for its index and base-4 address. Click two cells to compare their displacement.

What to try. Hover over the grid to see a square’s path number and address. Click one blue square, then another blue square. The panel compares them and checks the binary fingerprint used by the proof. White rings mark the formal selector’s chosen blue stops. Successive ring indices differ by 4–28. A difference of d means d Hilbert unit steps and d−1 indices strictly between the rings.

The proof connection: for two cells with the same terminal state, the first binary scale at which their planar positions differ exactly matches the power of two in the difference between their path indices. The proof writes this as V(H(n)−H(m)) = ν₂(n−m). This is the same-terminal-state pair law used in the collinearity contradiction.
